## git全局根据项目不同自动切换用户

```bash
cat ~/.gitconfig
```

```
[includeIf "hasconfig:remote.*.url:*github.com*/**"]
        path = ~/.gitconfig-github

[includeIf "hasconfig:remote.*.url:git@github.com:*/**"]
        path = ~/.gitconfig-github

[includeIf "hasconfig:remote.*.url:*://git@gitlab.cn*/**"]
        path = ~/.gitconfig-gitlab

[includeIf "hasconfig:remote.*.url:git@gitlab.cn:*/**"]
        path = ~/.gitconfig-gitlab
```
